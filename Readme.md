# AutoPrompt Annotator

**Интеллектуальный инструмент для разметки данных и оптимизации промптов мультимодальных моделей (видео, изображения, текст).**

## ?? О проекте

AutoPrompt Annotator — это локальный веб-сервис, который помогает создавать качественные датасеты для дообучения мультимодальных моделей (Video?XL?2, CLIP?ReID, YOLO, Qwen2?VL и др.) с использованием **Soft Prompting** и передовых методов **Context Optimization (CoOp / CoCoOp)**.

Сервис автоматизирует рутинные задачи: загрузку файлов, разметку, проверку промптов, наложение таймкодов на видео, разметку изображений прямоугольными областями, бенчмаркинг и даже генерацию скриптов для автоматической настройки контекстных векторов.

Проект разработан для работы в **закрытом контуре** (без доступа к интернету, кроме GigaChat API) и не требует базы данных. Всё хранится в файловой системе.

## ?? Возможности

- **Автоопределение типа данных** (видео, изображение, текст) и показ метаданных.
- **Адаптивный интерфейс** под ОС: Linux (ввод путей) и Windows (drag&drop + диалоги).
- **Потоковая разметка** с проверкой и улучшением промптов через GigaChat.
- **Наложение таймкода** на видео (предпросмотр через canvas + экспорт видео с «вшитым» временем с помощью FFmpeg).
- **Разметка изображений** прямоугольными областями с экспортом в YOLO, COCO, Pascal VOC.
- **Поддержка составных моделей** (например, Video?XL?2) через YAML-конфиги.
- **Генерация конфигураций моделей** через GigaChat (или ручное создание по примеру).
- **Автоматическая оптимизация промптов** методами CoOp / CoCoOp (генерация скриптов и запуск обучения).
- **Бенчмарк** модели до и после оптимизации: локальные метрики + анализ через GigaChat.
- **Встроенная справочная система** с туториалом и подсказками по каждому элементу интерфейса.

## ?? Технологический стек

- **Backend**: FastAPI (асинхронный)
- **Frontend**: HTML5, CSS3, Vanilla JS
- **Обработка медиа**: OpenCV, Pillow, FFmpeg
- **Конфигурация**: YAML + Pydantic валидация
- **Асинхронные запросы к GigaChat**: aiohttp / httpx
- **Сборка и запуск**: Uvicorn

## ?? Требования

- **Python** 3.12
- **FFmpeg** (установлен в системе и доступен в PATH)
- **CUDA 12+** (опционально, для аппаратного ускорения FFmpeg)
- **Операционная система**: Linux (рекомендуется) или Windows
- Доступ к **GigaChat API** (через существующий клиент)

## ?? Установка и запуск

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/Robberto73/Soft_prompt_service.git
cd Soft_prompt_service
```

### 2. Создайте виртуальное окружение
```bash
python -m venv venv
source venv/bin/activate      # Linux
venv\Scripts\activate         # Windows
```

### 3. Установите зависимости
```bash
pip install -r requirements.txt
```

### 4. Настройте GigaChat клиент
Сервис ожидает, что вы предоставите модуль с функцией `gigachat_request(prompt, system_prompt, timeout)`. Путь к нему указывается в конфигурации (по умолчанию импортируется из `external.gigachat`). Подробнее см. в документации по подключению.

### 5. Запустите сервер
```bash
uvicorn app:app --host 0.0.0.0 --port 5000 --reload
```

### 6. Откройте в браузере
```
http://localhost:5000
```

## ??? Использование (краткий сценарий)

1. **Загрузите файлы** (видео, изображения, текст) через drag&drop или укажите пути.
2. **Выберите модель** из списка (или добавьте свою через YAML-конфиг, сгенерированный GigaChat).
3. **Размечайте** в потоковом режиме: система показывает один файл, вы пишете вопрос и ответ, нажимаете «Сохранить и далее».
   - Для видео можно в любой момент вставить таймкод на текущий кадр.
   - Для изображений — нарисовать bounding box и присвоить класс.
4. **Проверяйте и улучшайте промпты** через кнопки «Проверить с GigaChat» и «Улучшить с GigaChat».
5. **Экспортируйте видео с таймкодом** (если нужно) — получите файл с видимым временем на каждом кадре.
6. **Запустите автоматическую оптимизацию** (CoOp/CoCoOp) — сервис сгенерирует скрипт и обучит контекстные векторы.
7. **Сравните качество** модели до и после оптимизации через встроенный бенчмарк.

Все датасеты сохраняются в JSONL, аннотации изображений — в выбранном формате (YOLO/COCO/VOC), а обученные векторы — в `storage/coop_outputs/`.

## ?? Структура хранения данных

- `storage/uploads/` – загруженные пользователем файлы.
- `storage/datasets/` – готовые датасеты (JSONL).
- `storage/annotations/` – аннотации изображений (YOLO, COCO, VOC).
- `storage/exports/` – видео с «вшитым» таймкодом.
- `storage/sessions/` – временные файлы прогресса разметки.
- `storage/coop_outputs/` – результаты CoOp/CoCoOp обучения.
